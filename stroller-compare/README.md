# BB車比較室

[開啟互動比較表](https://nigohkw.github.io/stroller-compare/)

八款BB車、20項規格放在同一張表。車款完整展開，沒有表格內部的上下捲動；車名、表頭和橫向導覽保持可見。支援車款篩選、排序及資料來源備註。

車名下的資料按鈕提供商家原圖及版本備註。台灣 SWAN Pro 保留原有來源；內地天鵝 Pro 參考淘寶、京東及其他內地資料；其他車款只補充淘寶／天貓而不引用京東。商家資料與官方／香港規格分開標示。

更新日期：2026-10-26。

純靜態 HTML、CSS 和 JavaScript，由現有 GitHub Pages 設定部署。
