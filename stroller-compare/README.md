# BB車比較室

[開啟互動比較表](https://nigohkw.github.io/stroller-compare/)

十一款BB車、21項規格放在同一張表。車款完整展開，沒有表格內部的上下捲動；車名、表頭和橫向導覽保持可見。支援車款篩選、排序及資料來源備註。

車名下的資料按鈕提供商家原圖及版本備註。台灣 SWAN Pro 保留原有來源；內地天鵝 Pro 參考淘寶、京東及其他內地資料；其他車款只補充淘寶／天貓而不引用京東。商家資料與官方／香港規格分開標示。

已加入 Joie Elipto、Nuna IXXA next 及 Nuna SWIV；各款推出日期附市場及事件性質，區分正式發售、發表、上市宣傳與最早有售紀錄。未能核實的首次上市日明確標示，不以設計獎年份代替。

更新日期：2026-10-26。
